# Scientific and support limitations

This Alpha supports the parser/residual/steady AD/root APIs and five
fixed RBC/NK starts on the one qualified macOS environment. Custom models in the
same grammar are experimental research use until users independently validate
their economics and numerical domain. Scope does not certify global uniqueness,
economic optimality, stationarity, empirical fit or arbitrary parameter regions.

Implemented but unsupported: dynamic date derivatives, canonical assembly, QZ,
BK, G/H recovery, innovation loading, causal L2-law admission and finite IRFs.
Their historical internal acceptance is preserved. Importability is not a support
promise. They still enforce their existing explicit evidence/source gates.

Internal validation infrastructure, enrollment records and historical raw logs
are not public package APIs and are not bundled. No default profile selector is
changed. G1/T1 remains exact-local-only; native ACTIVE/broader activation is absent.
No P3.10, stochastic simulation, estimation, higher-order or nonlinear IRF support.

No Linux/Windows scientific certification or successful cross-platform H recovery
is claimed. The theoretical H=1/2 and correctly refused native H=0 historical case
remain distinct. RBC-B policy/IRF independent golden evidence is unscored.
Dynare/Octave, EF-REF-1 and complete-system release gates remain incomplete.
The frozen full v0.1 release gate is not satisfied by this package's install tests.
