# Contributing to EconForge

This experimental Alpha supports only the documented steady-state scope. Use GitHub Issues for reproducible bugs and focused proposals.

Include the version and artifact SHA256, operating system, Python and dependency versions, numerical settings, minimal model JSON, explicit starting point, complete result and expected analytical behavior. Remove credentials, private datasets and unrelated logs. Preserve failures so they can be investigated.

Discuss numerical changes before implementation. Contributions must include a bounded explanation, relevant tests or analytical evidence, provenance of added material and known limitations. Do not change mathematical tolerances, reference answers, phase boundaries or scientific acceptance claims as incidental cleanup. The presence of an advanced module does not authorize broader support claims.

Only submit material you have authority to contribute. Identify third-party material and retain required license and attribution notices. No contributor agreement or transfer of rights is implied. The project is distributed under the MIT License; preserve legitimate third-party notices.
