# Research practice and contributions

Use the package to inspect reproducible local equation and root calculations. Check your model against independent analytical or external evidence before relying on a new model or parameter region. PASS applies only to the recorded checks; it is not a complete economic-model certificate.

Follow the root README for citation and the contribution guide for bug reports and pull requests. After publication, report issues at https://github.com/finleydoudou/EconForge-Alpha/issues with the artifact hash, environment, minimal model and explicit initial guess, full diagnostics and the expected analytical result. Omit secrets and private data.

Cite EconForge version 0.1.0a1, Experimental Alpha, the published GitHub Release, exact artifact SHA256 and access date. Cite economic equations separately. No DOI, publication, author list or institutional endorsement is invented.
